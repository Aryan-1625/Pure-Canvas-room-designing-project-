# 🎨 Pure Canvas

**A Modern Room Designing Application**

## Overview

Pure Canvas is a modern room designing application designed to help users visualize and customize interior spaces through an interactive design environment.

The project aims to simplify room planning by providing tools for arranging interior elements, exploring layouts, and creating personalized room designs.

## Features

- **Interactive Design Workspace:** Create and customize room layouts.
- **Room Customization:** Arrange and modify interior design elements.
- **2D/3D Visualization:** Explore room designs through visual representations.
- **Asset Management:** Access and organize design elements for room customization.
- **User-Friendly Interface:** Simple and intuitive design experience.

## Tech Stack

The project uses modern web development technologies.

- **Frontend:** React.js, TypeScript
- **Styling:** Tailwind CSS
- **Build Tool:** Vite
- **3D Rendering:** Three.js / WebGL

## Prerequisites

Before running the project, make sure you have the following installed:

- [Node.js](https://nodejs.org/) (LTS version recommended)
- npm (Node Package Manager)
- Git

## Installation & Local Setup

Follow these steps to run Pure Canvas on your local machine.

**1. Clone the repository**

```bash
git clone https://github.com/Aryan-1625/Pure-Canvas.git
```

**2. Navigate to the project directory**

```bash
cd Pure-Canvas
```

**3. Install dependencies**

```bash
npm install
```

**4. Start the development server**

```bash
npm run dev
```

**5. Open the application**

Open the local URL displayed in your terminal (usually `http://localhost:5173`) in your browser.
